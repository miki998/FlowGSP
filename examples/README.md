# FlowGSP Examples

This directory contains example scripts and notebooks demonstrating how to use the FlowGSP framework.

## Directory Structure

### `basic/`
Contains introductory examples for getting started with FlowGSP:
- Basic graph creation and manipulation
- Simple filtering operations
- Graph visualization
- Fundamental signal processing tasks

**Start here if you're new to FlowGSP!**

## Quick Start

To run any example:

```bash
# For Python scripts
python examples/basic/01_basic_graph.py

# For Jupyter notebooks
jupyter notebook examples/basic/01_basic_graph.ipynb
```

## Example Notebooks from Original Repository

The original repository contains additional notebooks in:
- `tutorials/` - Basic and advanced tutorials
- `notebooks/` - Research and experimental notebooks
- `figure_notebooks/` - Notebooks for generating paper figures

## Requirements

All examples require the FlowGSP package to be installed:

```bash
pip install -e .
```

Some advanced examples may require additional dependencies specified in the example file.
