# Basic Examples

This directory contains introductory examples for getting started with the FlowGSP framework.

## Examples Overview

### Getting Started
These examples introduce the core concepts of directed graph signal processing:

1. **Graph Creation** - Creating and manipulating directed graphs
2. **Graph Operators** - Understanding Laplacian and Adjacency.
3. **Signal Processing** - Basic graph signal operations
4. **Filtering** - Simple filtering on graphs
5. **Visualization** - Plotting graphs and signals

## Running Examples

Each example is self-contained and can be run independently:

```bash
# If using Python scripts
python 01_graph_creation.py

# If using Jupyter notebooks
jupyter notebook 01_graph_creation.ipynb
```

## Prerequisites

Basic knowledge of:
- Python programming
- Linear algebra (matrices, eigenvectors)
- Signal processing concepts (filtering, Fourier transform)
- Basic graph theory

## Learning Path

We recommend following the examples in order:
1. Start with graph creation and manipulation
2. Learn about different graph operators
3. Explore signal processing on graphs
4. Practice filtering techniques
5. Visualize your results
