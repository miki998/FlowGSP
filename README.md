This is the public version of my GSP framework employed to investigate directed graph fourier transform. Generalizing operations such as filtering, sampling and time/phase-shifting. 

### Purpose

To publish this package in [FlowGSP](https://test.pypi.org/project/flowGSP) in testpypi.

### Installation

Run the command if you already have all the required packages:
`pip install -i https://test.pypi.org/simple/ flowGSP`

Otherwise run the command:
`pip install --index-url https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ flowGSP`
