Citing GyRAPH
=============

If GyRAPH is useful in academic work, please cite it. Machine-readable metadata
lives in `CITATION.cff
<https://github.com/miki998/GyRAPH/blob/main/CITATION.cff>`_.

.. code-block:: bibtex

   @software{chan_gyraph,
     author  = {Chan, Chun Hei Michael},
     title   = {{GyRAPH}: Directed Graph Signal Processing Framework},
     url     = {https://github.com/miki998/GyRAPH},
     license = {MIT}
   }

If you use a specific method, please also cite the paper it comes from — see
:doc:`papers`.
